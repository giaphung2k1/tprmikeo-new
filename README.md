# TPR | Mike O — Keynote & Transformational Speaker

A modern web application for Mike O — Multidisciplinary Keynote Speaker, featuring the TPR Framework (Thrive, Pursue, Respond).

## Tech Stack
- React 19
- Vite
- Vanilla CSS Design System
- Lucide React

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
